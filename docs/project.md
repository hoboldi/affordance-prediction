This is a project about open-vocabulary affordance prediction using SAM3D and VLM context. The rough outline is to use an image together with a open-vocabulary verb as input, generate a 3D model using SAM3D, sample novel 3D views, feed these views into a VLM and project latents of VLM patches onto SAM3D-generated mesh. Together with latent of SAM3D, the latents of each vertex should be fed into a lightweight classification head that then predicts the verb-conditioned affordance in the range [0, 1] for each vertex.
